Rho PDF is a free x64 desktop application for supported Windows 10 and Windows 11 PCs.

Contact support

Email atomsprout@gmail.com. Please include the Rho PDF version, Windows version, what you expected, and what happened. Do not attach confidential documents.

Common questions

Does Rho PDF upload my documents?

No. PDF processing and Ask Rho inference run locally. See the privacy policy.

Why is Ask Rho not ready immediately?

Ask Rho is optional and requires a compatible local model. Downloads begin only after you choose a model. You may also import a model package offline.

Can Rho PDF read scanned documents?

Scanned PDFs may contain images without searchable text. The current release reports this limitation; OCR is not yet included.

How do updates work?

Microsoft Store installations are updated through the Store. The Help > Check for updates command opens the public release page in your browser.

How do I uninstall?

Open Windows Settings, choose Apps > Installed apps, find Rho PDF, and select Uninstall.

Refunds and purchases

The current release is free and contains no in-app purchases. If paid products are introduced later, Microsoft Store purchase and refund policies will apply.
